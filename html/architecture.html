ProLaptop Mobile

App mua hàng chạy như thế nào

Đây là app dành cho khách hàng: đăng ký, xem laptop theo hãng, thêm vào giỏ, đặt hàng (tiền mặt hoặc ZaloPay), xem đơn, đánh giá và chat với admin. Viết bằng React Native, chạy qua Expo, gọi cùng server NestJS với trang admin.

Expo SDK 52React Native 0.76
22màn hình (18 stack + 4 tab)
10file repository gọi API
prolaptop://scheme để mở lại app

Nhìn từ xa

Navigation chọn màn hình. Màn hình gọi repository, repository dùng axios gửi HTTP tới server. Nét đứt: đọc dữ liệu đăng nhập dùng chung, kênh chat, và việc mở app ZaloPay để thanh toán.

Khái niệm cốt lõi

Các khái niệm cốt lõi của React Native

React Native dùng đúng cách nghĩ của React (component, props, state, effect) nhưng vẽ ra giao diện điện thoại thay vì HTML. Tám khái niệm dưới đây có mặt ở hầu hết file trong project.

Componentcomponents/LaptopItem.js

Một hàm trả về giao diện. Mỗi màn hình, mỗi thẻ sản phẩm đều là component. Tên viết hoa và dùng như một thẻ: <LaptopItem item={p} />.

export default function LaptopItem(props) {
  return <Text>{props.item.name}</Text>;
}

StateuseState

Dữ liệu màn hình tự giữ và thay đổi được: danh sách, số lượng trong giỏ, đang loading… Gọi set… là React vẽ lại màn hình.

const [categories, setCategory] = useState([]);

EffectuseEffect · useFocusEffect

Code chạy sau khi màn hình đã vẽ: gọi API, mở socket. useFocusEffect của React Navigation chạy lại mỗi lần quay về màn hình, dùng cho giỏ hàng để luôn thấy dữ liệu mới.

useEffect(() => { fetchCategories(); }, []);
// [] = chỉ chạy 1 lần khi màn hình mở
Contextcontexts/AccountContext.js

Kho dữ liệu dùng chung cho mọi màn hình. Ở đây giữ token và account của khách sau khi đăng nhập. Đọc bằng useContext hoặc useAuth().

const { account } = useContext(AccountContext);
cartAPI.getCart(account.id);

Vòng đời một thao tác

Một lần chạm đi qua những đâu

Chọn một ví dụ. Mỗi thao tác của khách đi qua cùng một chuỗi bước, từ màn hình tới server rồi quay về màn hình. Bước sáng là bước được chạy, bước mờ là bị bỏ qua.

    Bước Server chính là toàn bộ Request Lifecycle (Middleware → Guard → Pipe → Controller → Service → Database) trong tài liệu server.

    Các luồng chính

    Từng tính năng chạy ra sao

    Sắp theo thứ tự dữ liệu được tạo ra: phải có tài khoản trước, rồi mới có giỏ hàng, rồi đơn hàng, rồi đánh giá. Mọi URL có tiền tố /api. Sơ đồ đọc từ trên xuống theo thời gian.

    Cần lưu ý

    Những điểm nên biết trước khi sửa code

    1
    Giỏ hàng bị xoá trước khi thanh toán

    Bấm "Payment" ở giỏ là các món đã chọn bị DELETE ngay (screens/cart/index.js). Khách quay lại không đặt nữa thì mất giỏ.

    2
    ZaloPay tạo đơn hai lần

    App gọi POST /order/create-from-cart trước, rồi khi ZaloPay báo thành công, callback ở server lại tạo đơn thêm một lần nữa.

    3
    Biến toàn cục ngầm trong constants/

    Các file viết export default colors = {...}, vô tình tạo biến toàn cục. 10 file (9 màn hình và UITab.js) dùng colors mà không import và vẫn chạy nhờ điều đó. Chạy trên web (strict mode) sẽ báo colors is not defined. Cách sửa: const colors = {...}; export default colors; rồi thêm import.

    4
    URL server ghi cứng ở 3 chỗ

    formData trong axiosClient.js, Chat.js và hooks/socket.js luôn gọi bản deploy, bỏ qua .env. Đăng ký, đổi ảnh, đổi mật khẩu và chat vì vậy không đi vào server local.

    5
    Đăng nhập không bền

    Token chỉ nằm trong RAM: tắt app là mất. Lúc mới mở, header là Bearer null (so sánh với chuỗi "null"). Đăng xuất chỉ chuyển về Login, không xoá token.

    6
    Deep link mới làm một nửa

    Code đọc URL lúc mở app nhưng không dùng kết quả; và server đang cấu hình cho ZaloPay quay về trang web chứ không phải prolaptop://Success. Trong Expo Go, scheme prolaptop:// cũng không chạy.

    7
    Expo Go mới không chạy SDK 52

    Expo Go trên iPhone chỉ hỗ trợ SDK mới nhất. Bản đã nâng lên SDK 58 và chạy được trên web nằm ở nhánh thang/expo-sdk-58.

    8
    Thư viện thừa và thiếu

    Cài nhưng không dùng: redux, react-redux, react-router-*, react-navigation v5, yarn, add. Dùng nhưng không khai báo: query-string, @expo/vector-icons. ID admin ghi cứng trong Chat.js và messageApi.js.
